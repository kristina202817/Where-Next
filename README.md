# Where Next

A gesture-controlled travel picker: browse destination cards, compare cities head-to-head and get your boarding pass, all with hand gestures in front of your webcam.

Designed and prototyped in Figma Make.

## Tech
React · TypeScript · Vite · Tailwind CSS · MediaPipe Hand Tracking

## Run locally
```bash
pnpm install
pnpm dev
```
